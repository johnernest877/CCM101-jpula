# Laboratory 06: Cloud Deployment Engineer

## Mission Overview
This mission focuses on deploying a multi-tier private cloud storage solution (Nextcloud + MariaDB) using Docker Compose. It transitions from manual container deployment to Infrastructure as Code (IaC) principles.

## Objectives
- Understand multi-tier application architecture.
- Create and manage a `docker-compose.yml` file.
- Deploy and tear down a multi-container stack using CLI.
- Document IaC principles and reflect on the deployment process.

## Commands Executed
- `mkdir nextcloud-deployment && cd nextcloud-deployment`
- `nano docker-compose.yml`
- `docker-compose up -d`
- `docker-compose ps`
- `docker-compose down`

## Skills Learned
- Writing YAML configuration files for Docker Compose.
- Understanding internal Docker networking and environment variables.
- Applying Infrastructure as Code (IaC) best practices.
