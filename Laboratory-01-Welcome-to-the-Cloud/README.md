# 💻 Linux Commands Used
| Command | Description |
|----------|-------------|
| `sudo adduser` | Create a new user with a home directory |
| `sudo usermod -aG sudo` | Grant sudo privileges to a user |
| `su -` | Switch to another user with a full login shell |
| `whoami` | Display the current logged-in username |
| `pwd` | Display the current working directory |
| `hostname` | Display the system hostname |
| `getent passwd` | Verify user account details, including login shell |
| `lsb_release -a` | Display Linux distribution information |
| `uname -r` | Display the kernel version |
| `lscpu` | Display CPU information |
| `free -h` | Display total and available memory |
| `df -h` | Display available disk space |
| `mkdir` | Create new directories |
| `nano` | Create and edit files |
| `cat` | Display the contents of a file |
| `ls` | List files and directories |
| `git clone` | Clone a GitHub repository into the local environment |
| `git status` | Check the state of the working directory and staged changes |
