# Reflection

Completing Laboratory Activity 1 gave me a hands-on introduction to what working as a cloud engineer actually involves. 
Using KillerCoda helped me get comfortable navigating a Linux environment through the terminal from creating a new 
user with proper permissions, to gathering system information like the OS distribution, kernel version, CPU, memory, 
and disk space.

Building the folder structure and documenting everything in Markdown taught me the importance of organization and 
clear technical writing, both of which are essential in real cloud infrastructure work. I also learned how version 
control with Git and GitHub plays a role in maintaining a professional portfolio, since every lab activity will build 
on this same repository throughout the semester.

One challenge I ran into was mixing up user permissions and directories (for example, accidentally working as root 
instead of my own user account), which helped me better understand how Linux user management and file ownership work.
