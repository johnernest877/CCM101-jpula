# Mission Reflection

## 1. Which cloud infrastructure component do you think is the most important? Why?

The **compute component** is the most vital part of cloud infrastructure because it provides the core processing power and memory needed to execute code, run services, and handle active workloads. Without compute resources, applications cannot operate. Selecting the right compute capacity directly determines a system's overall performance, operational reliability, and cost-efficiency within a cloud environment.

## 2. How does Linux support cloud computing?

Linux supports cloud computing by serving as a highly stable, secure, lightweight, and adaptable operating system for virtualized environments. Its command-line interface enables efficient administration and resource management. During this activity, I used Linux commands to inspect hardware topology, memory allocation, block storage usage, and network settings. Linux is the standard choice for enterprise cloud infrastructure due to its open-source flexibility and seamless support for automation and containerization.

## 3. Why is technical documentation important before deploying infrastructure?

Technical documentation is essential because it creates a clear blueprint of system architecture, configurations, and resource dependencies before deployment. It reduces implementation errors, speeds up troubleshooting, and ensures security compliance. Comprehensive documentation also enables engineering teams to collaborate effectively, prevent configuration drift, and reliably replicate environments whenever required.

## 4. What new skills did you learn during this laboratory activity?

I learned how to use essential Linux CLI tools to audit system hardware and operating system parameters. Additionally, I gained hands-on experience structuring technical reports using Markdown, managing version control via Git and GitHub, and designing visual infrastructure architecture diagrams using draw.io.

## 5. How has your GitHub portfolio improved after completing this mission?

My GitHub portfolio improved by adding a well-structured, fully documented cloud engineering project. Maintaining clean directory hierarchies, publishing detailed technical analysis files, attaching architecture diagrams, and keeping clean Git commit histories demonstrates my practical competency in cloud infrastructure assessment and technical documentation.
