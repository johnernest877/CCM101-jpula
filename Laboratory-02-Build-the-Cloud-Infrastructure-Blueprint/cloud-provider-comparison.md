# Cloud Provider Comparison

This comparison examines the similar infrastructure services offered by **Amazon Web Services (AWS)**, **Microsoft Azure**, and **Google Cloud Platform (GCP)**.

---

## Infrastructure Service Comparison

| **Infrastructure Component** | **AWS** | **Microsoft Azure** | **Google Cloud (GCP)** |
|---|---|---|---|
| **Compute** | Amazon EC2 | Azure Virtual Machines | Compute Engine |
| **Storage** | Amazon S3 | Azure Blob Storage | Cloud Storage |
| **Networking** | Amazon VPC | Azure Virtual Network | VPC |
| **Identity and Access Management** | AWS IAM | Azure RBAC | Cloud IAM |

### Compute

Amazon EC2, Azure Virtual Machines, and Compute Engine provide virtual computing resources for running applications and workloads.

### Storage

Amazon S3, Azure Blob Storage, and Cloud Storage provide cloud storage for files, objects, and other data.

### Networking

Amazon VPC, Azure Virtual Network, and Google Cloud VPC provide virtual networks for connecting and managing cloud resources.

### Identity and Access Management

AWS IAM, Azure RBAC, and Cloud IAM control who can access cloud resources and what actions they can perform.

---

## Guide Questions

### 1. Which cloud provider offers the broadest range of services?

**AWS** offers a broad range of cloud services, including compute, storage, networking, databases, security, analytics, and AI.

### 2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products? Why?

I recommend **Microsoft Azure** because it integrates well with Microsoft technologies such as Windows Server, SQL Server, and Microsoft Entra ID.

### 3. Which platform is widely recognized for AI, ML, and Kubernetes services?

**Google Cloud** is well known for AI, machine learning, and Kubernetes services, including **Google Kubernetes Engine (GKE)**.

### 4. What similarities did you observe among the three cloud providers?

All three providers offer similar core services for **compute, storage, networking, and identity and access management**. The main difference is their service names and features.
